# Contributing

This repository is maintained by Databricks employees for public demonstration content.

- Open an issue before proposing a material change.
- Only Databricks maintainers may commit or merge code. External suggestions must be independently reproduced by a maintainer.
- All changes must use a pull request into protected `main`; direct pushes are prohibited.
- The initial publication requires an L7+ Databricks reviewer. Later changes require reviewers appropriate to their security and product impact.
- Update the dependency-license table in `README.md` whenever a library changes.
- Never include credentials, customer data, customer code, or internal-only material.
- Run the local tests and ensure the `quality` workflow passes.
- Test against a currently supported Databricks Runtime and document the workspace/profile used in the pull request. Never add a workspace profile to source control.

By contributing, you agree that the change is distributed under this repository's Databricks License.
